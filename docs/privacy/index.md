# 隐私政策

本站尊重并保护所有访问者的隐私权益：
- 本站作为静态内容展示平台，不设置强制注册或收集用户个人隐私信息。
- 本站采用轻量静态站内搜索，搜索词仅在本地或静态索引中匹配，不上传第三方追踪。
