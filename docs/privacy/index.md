# 隐私政策与数据保护声明

**机场推荐**（jichangtuij.com）高度重视访客的个人隐私与数据安全。本隐私政策旨在向您说明本网站在您访问期间如何处理与保护信息，以及我们坚持的最小化数据原则。

---

## 一、信息收集原则：零用户追踪

本网站为纯静态内容网站（Static Site Generation, SSG），我们在架构设计层面从根本上杜绝了对用户隐私的侵入性收集：

1. **无需注册与登录**：本站不设任何用户注册系统、不设会员中心、不收集任何用户的真实姓名、手机号码或电子邮箱地址；
2. **不收集金融与支付信息**：本站不开展任何在线销售业务，不处理任何银行卡号、支付宝或微信支付凭证；
3. **无侵入性第三方分析探针**：本站未接入任何跨站广告追踪网络，未嵌入任何窃取访客指纹信息的脚本。

---

## 二、本地存储与 Cookie 使用规范

- **必要的功能性存储**：为了提供良好的浏览体验，本站可能使用浏览器标准的 `localStorage` 仅用于记录您的视觉主题偏好（如明亮模式/暗黑模式切换）及站内搜索历史；
- **纯本地运算**：本站内置的 Pagefind 全文搜索完全运行在您的本地浏览器沙盒环境中，您在搜索框中输入的任何查询词均不会上传至服务器后台数据库。

---

## 三、第三方外链免责声明

本站文章包含指向第三方服务商（如机场官网、开源客户端代码仓库 GitHub 等）的外部超链接。当您点击这些链接离开本站时，您的网络行为将受该第三方站点的隐私政策约束。我们强烈建议您在向任何第三方服务商提供个人信息或进行金融支付前，仔细审阅其官方隐私政策。

---

## 四、隐私政策的修订

我们可能会根据技术架构演进或法律法规要求适时更新本隐私政策。任何更新将直接发布于本页面，并在顶部更新生效日期。
