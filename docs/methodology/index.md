# 评测方法论与数据分级规范

为确保全站信息的准确与客观，我们采用严格的 **四层数据分离模型**：

1. **Vendor (厂商声明)**：价格、名义流量、协议、架构声明。
2. **Measured (本站实测)**：保留时间戳（如 2026-08-11）的原始测速截图与测试环境。
3. **Commercial (商业信息)**：优惠码、推广链接、支付渠道。
4. **Editorial (编辑判断)**：适合人群、不适合人群、优缺点客观分析。
