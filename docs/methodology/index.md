# 评测方法论与风控模型规范

在鱼龙混杂的代理服务市场中，单一维度的测速跑分或情绪化的主观评价往往极易产生误导。为了让评测结论具备科学性、可验证性与行业参考价值，**机场推荐**（jichangtuij.com）建立了标准化的技术评测方法论与服务商风控评级模型。

---

## 一、网络性能测试标准与口径

我们拒绝脱离测试条件得出任何性能定论。本站所有测速与延迟数据均严格遵循以下技术采集口径：

### 1. 物理机房与测试网络基线
- **基准测试节点**：采用固定骨干网测试服务器（如华南珠海联通 5Gbps 高性能机房）；
- **压测线程规范**：采用标准化的 32 线程持续并发测速工具，模拟真实大带宽瞬时吞吐；
- **时段标注制度**：所有测试数据必须明确加注测试时间点（区分白天低峰与晚间 20:00~23:00 骨干网峰值时段）。

### 2. 核心网络性能三大指标
1. **TCP 握手时延与抖动（Jitter）**：评估本地到跨境入口的延迟稳定性。标准差小于 3ms 视为专线优秀水平，标准差大于 15ms 提示存在公网路由拥堵；
2. **晚高峰丢包率（Packet Loss）**：在网络最拥塞的 21:00~22:30 进行百次 ICMP/TCP 探测。真正的内网物理专线（IEPL）在骨干段丢包率应趋近于 0%；
3. **下行与上行有效带宽（Throughput）**：测试 4K/8K 视频播放缓冲区填充速率。

## 二、功能特性分级核验口径

对于厂商宣传的“支持 AI、解锁 Netflix 等流媒体”等功能点，我们实行三级严格界定：

| 标记级别 | 技术定义 | 消费者参考价值 |
|---|---|---|
| **实测确认 (Measured)** | 本站工程师在标注日期通过测试脚本真实复核，确认可用 | 近期高确定性可用 |
| **品牌声明 (Vendor Claim)** | 来源于服务商官方宣传，本站尚未完成连续周期自动化监测 | 具有参考性，但需以实时体验为准 |
| **待独立复核 (Review Required)** | 暂无标准化截图或处于风控策略调整期 | 建议优先购买月付测试 |

## 三、服务商风控与避坑评估模型

除了网络物理性能外，服务商自身的商业与运营稳定性是决定用户资金安全的关键。我们建立了“五维风控评分矩阵”：

```mermaid
radar-beta
  title "服务商综合风控评估维度"
  "运营年限沉淀" : 80
  "协议与架构现代化" : 85
  "纯月付支持度" : 90
  "多线BGP入口冗余" : 75
  "退款与客服响应" : 70
```

1. **存续年限（Established Track Record）**：开业超过 2 年以上的服务商在服务器资源、上游线路采购与防跑路信誉上显著优于新上线 3 个月的小作坊；
2. **支付周期灵活性（Payment Flexibility）**：坚持支持单月支付的服务商，其资金链透明度与对自身服务质量的信心远高于“仅限年付”的服务商；
3. **架构真实性（Route Authenticity）**：通过网络追踪（MTR）核验跨境段是否真实存在内网物理专线，杜绝使用普通公网中转冒充专线收取高额溢价；
4. **长周期容灾储备（Redundancy Capacity）**：在遭遇大型网络阻断时，是否具备充足的备用入口与备用域名系统。
