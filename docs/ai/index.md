## AI 平台的 3 大选型原则

1. **地区选择**：推荐使用 **美国、新加坡、日本、台湾** 节点；香港节点已被大多数 AI 官方明确列为不支持地区。
2. **出口 IP 纯净度**：万人共用机房 IP 极易触发 Cloudflare 5 秒盾与账号被封风控，需要选择出口具有原生住宅/商用纯净 IP 的服务商。
3. **会话保持 (Sticky Session)**：频繁切换出口 IP 会触发风控登出，推荐使用支持会话保持的专线节点。
