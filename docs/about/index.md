# 关于机场推荐 (jichangtuij.com)

**机场推荐** 专注于为中文用户提供客观、透明、可复核的代理节点服务（机场）选型参考与技术教程。

## 我们的原则
1. **厂商数据与实测证据严格分离**：不将厂商自称的“支持AI/解锁流媒体”伪装成本站实测。
2. **测速证据保留时间戳**：明确标注 2026-08-11 测试日期与测试环境，拒绝虚构全网第一。
3. **推广关系透明披露**：显著标注推广链接，确保商业合作不影响事实陈述。
