## 流媒体追剧设置建议

1. **启用 UDP 与 HTTP/3**：在客户端中开启 UDP 转发支持，可以让 YouTube 与 Netflix 走 QUIC 协议传输，加快缓冲速度。
2. **选择就近低延迟区域**：南方宽带首选香港、台湾、新加坡节点；北方宽带首选日本、韩国节点。
3. **保持月付验证习惯**：流媒体版权风控策略更新较快，先按月购买验证各区解锁状态后再考虑续费。
