## 数据来源与核验规范

1. **厂商数据 (Vendor Data)**：套餐资费、节点数量、自研客户端与功能声明均源自品牌公开规格。
2. **实测证据 (Measured Evidence)**：所有测速图均来自本站实机测速记录，保留原始测试时间。
3. **商业披露 (Commercial)**：推广注册链接已核验，包含 Hash 路径的链接严格原样保存。
