## 选机场的核心判断法则

1. **先看线路，再看协议**：公网直连易受 GFW 干扰；IEPL 跨境内网专线物理过境，晚高峰丢包率显著更低。
2. **先选月付，验证后再考虑长周期**：首次使用建议按月付费，在本地运营商（电信/联通/移动）实测流畅后再决定是否长期续费。
3. **警惕永久与超低价无限流量陷阱**：服务器与专线带宽均为持续成本支出，所谓“永久免费/超低价无限量”往往伴随超售甚至跑路风险。
