# 故障排查相关内容

<AnswerBox />

网络不通时，最忌讳的是盲目乱试 —— 乱改 DNS、频繁重装软件、乱换数十个节点，结果不仅没解决问题，反而把原本正确的配置改乱了。科学排查的核心是**二分法定位瓶颈**。

这个标签聚合了所有阶梯式故障排查指南：包括**全断类故障**（全部节点超时、订阅更新报错 404/500）、**单端异常类故障**（WiFi 能用移动流量不能用、全局模式可用但规则模式打不开）、**特定场景故障**（ChatGPT 拒绝访问、Netflix 提示使用代理）。

遇到问题时，请严格按照各指南给出的五步排查法执行：先看本地网络 → 再看客户端全局模式 → 再检查订阅凭证 → 最后核验节点与出口。这一逻辑能帮你定位 95% 以上的常见故障。
