# 基础概念相关内容

<AnswerBox />

这个领域大多数困惑不是因为信息不够，而是因为概念被混用。订阅被当成节点、节点被当成线路、线路被当成服务商，结果排查时找错方向、比较时得出错误结论、看广告词时无法判断真假。

这个标签聚合的是所有「先把话说清楚」的内容：**订阅**是一条会更新的节点列表链接；**节点**是列表里的一条具体服务器配置；**线路**是数据从本地到目标网站经过的完整路径，包含入口、中转、出口三段；**客户端**是决定哪些流量走这条路径的本地程序。四者层层嵌套，任何一层出问题的表现都可能是「连不上」，但处理方式完全不同。

把这四个概念区分清楚，通常只需要一个小时的阅读，但它会显著降低之后每一次判断的成本。建议在购买任何服务之前先读完这一组内容。
