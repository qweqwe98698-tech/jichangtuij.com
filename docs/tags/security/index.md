# 安全相关内容

<AnswerBox />

「安全吗」这个问题实际包含四个不同的子问题：传输内容会不会被看到、服务商本身是否可信、账号与支付信息是否会被滥用、订阅凭证会不会泄漏。四者的风险来源与应对方法完全不同，混在一起讨论只会得到模糊答案。

这个标签下的内容按层拆解各自的真实风险边界与可执行的核验方法，重点在「可核验」三个字 —— 无法验证的承诺不构成安全保证。
