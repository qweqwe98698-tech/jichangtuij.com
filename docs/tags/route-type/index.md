# 线路类型相关内容

<AnswerBox />

直连、中转、专线不是「好坏三档」，而是三种不同的成本与稳定性取舍。看懂它们的差别，才能判断一个套餐的定价是否合理，也才能在出问题时判断瓶颈发生在哪一段。

这个标签聚合的内容说明每种线路的路径结构、各自最容易拥堵的位置，以及在什么使用场景下哪一种更合适。
