# 客户端相关内容

<AnswerBox />

客户端是运行在你自己设备上的程序，负责把系统流量按规则送到选中的节点。它决定的是「哪些流量走代理、域名怎么解析」，而不是「线路有多快」。同一份订阅在不同客户端上表现不同，绝大多数时候来自规则集版本与 DNS 设置的差异，而不是节点本身。

这个标签聚合的内容围绕三件事展开：**客户端在整条链路中处于什么位置**（它上游是订阅、下游是目标服务）、**规则模式与全局模式的分工**（前者日常使用，后者用于排错分界）、**配置错误的典型症状**（能连上但特定网站打不开、开了 TUN 反而全网不通、地区判定与节点显示不一致）。

一个实用的判断技巧贯穿这些内容：把客户端切到全局模式测一次。如果全局可用而规则模式不可用，问题一定在规则或 DNS，与线路无关 —— 这一步能把排查范围直接砍掉一半。
