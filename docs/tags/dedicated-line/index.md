# 专线相关内容

<AnswerBox />

专线是溢价最高、也最容易被滥用的线路标签。它对应真实存在的运营商产品，但标签本身不构成任何技术保证 —— 服务商在专线上卖了多少用户，完全由服务商决定。

这个标签下的内容集中回答三个问题：专线到底解决了什么（跨境链路拥堵）、没解决什么（超售、本地接入质量、平台的出口判定），以及如何从价格合理性、结构透明度与晚高峰实际表现三个角度交叉判断标签是否名副其实。
