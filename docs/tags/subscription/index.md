# 订阅相关内容

<AnswerBox />

订阅是使用机场服务时接触到的第一个概念，也是最容易被误解的一个。它不是一个软件、不是一台服务器，而是一条会持续更新的链接：客户端按周期访问它，取回当前可用的节点列表。理解这一点之后，很多现象会立刻变得可解释 —— 为什么服务商说加了新节点但你看不到、为什么流量显示总是滞后、为什么「全部节点突然失效」多数时候和线路无关。

这个标签横向聚合了三类内容：**机制说明**（订阅怎么工作、和节点与客户端的分工）、**故障处理**（更新失败、列表为空、流量异常消耗时的排查顺序）、**安全边界**（订阅链接本身就是凭证，泄漏意味着什么、发现后按什么顺序处理）。

如果你是第一次接触，建议按「机制 → 故障 → 安全」的顺序阅读；如果你正在排查具体问题，可以直接从故障类内容进入。
