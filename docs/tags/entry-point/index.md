# 入口相关内容

<AnswerBox />

一条线路可以拆成三段：设备到入口服务器（国内段）、入口到出口（跨境段）、出口到目标网站（境外段）。**入口是唯一与你本地网络直接相关的一段**，也是同一份订阅在不同人手里体验相差最大的原因 —— 跨境段和境外段对所有用户基本一致，入口段却因运营商、城市、接入方式而异。

入口决定的事情比多数人以为的多：你所在运营商与入口机房之间的互联质量、延迟的基线水平，以及晚高峰时最先出现拥堵的位置。这也解释了两个高频现象 —— 「别人强烈推荐的节点在我这里很慢」（推荐者的运营商与城市和你不同，他验证的是他那一段），以及「换了几十个节点都没用」（这些节点共用同一个入口，换来换去始终没离开出问题的那一段）。

这个标签聚合的内容包括：入口与出口的区别与各自的确认方法、不同线路组织方式（直连、中转、BGP 多线接入）在入口段的结构差异，以及运营商适配类内容里的多入口对照测试方法。判断一个入口是否适合自己没有捷径可走：**在自己的网络上测，并且用晚高峰时段的数据测** —— 别人的结论只能当候选名单。
