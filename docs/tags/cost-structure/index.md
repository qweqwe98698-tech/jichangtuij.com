# 成本结构相关内容

<AnswerBox />

价格是这个领域最容易被单独拎出来比较、也最容易误导人的指标。脱离成本结构看价格，能得到的只有「便宜」和「贵」两种印象；把成本拆开看，同样的月费可以对应完全不同的东西 —— 带宽是独享还是共享、跨境段走公网还是专线、超售的代价由谁承担、服务周期内的运营成本算没算进去。

这个标签横向聚合三类内容：**成本来源**（直连、中转、专线分别贵在哪一段，为什么专线的价格下限受制于运营商侧的采购成本）、**价格与取舍的对应关系**（同一价位内，节点数量、带宽上限与高峰期表现之间必然此消彼长，多出来的一项一定从别处扣）、**成本可行性的判断**（当一个报价明显低于它所声称的线路类型应有的成本区间时，差额总要由某种方式补上 —— 提高共享比例、限制实际可用带宽、缩短实质服务周期，或者依赖新用户的持续流入）。

贯穿这些内容的方法不是比价，而是**追问成本花在哪一段**：让报价与它声称的线路类型、带宽承诺、服务周期三者对得上。对不上的时候，问题通常不在价格本身，而在没有说出口的那部分取舍。这套判断同样适用于长周期与不限期类套餐 —— 单价越低、承诺周期越长，越需要解释清楚成本从哪里来。
