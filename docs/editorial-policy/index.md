# 网站编辑原则与事实核验规范

为了维护**机场推荐**（jichangtuij.com）作为独立技术与消费参考平台的公信力，我们制定并公开发布本《编辑原则与事实核验规范》。全站所有评测文章、对比指南与教程内容均受本规范约束。

---

## 一、核心编辑标准

### 1. 首段直奔主题，解答核心问题
所有评测与科普文章在首段必须直接给出核心事实或选型结论，避免无意义的冗长铺垫。对于用户搜索的查询意图，提供立即可读、有事实依据的解答。

### 2. 严禁使用虚假营销与绝对化违禁词
在所有已发布内容中，严禁出现以下违背网络工程客观规律的宣传词汇：
- 严禁声称“100% 绝对稳定、永不封锁、全网第一”；
- 严禁将个别用户的特殊高速体验泛化为“全网通用体验”；
- 严禁隐瞒重大服务故障、跑路历史或严重丢包事实。

### 3. 数据来源可追溯
页面上展示的每一项关键数据均需标明来源：
- **资费与流量参数**：直接溯源至服务商官方网站在售产品详情；
- **测速数据**：必须附带原始测速截图、测试时间点、测试运营商与多线程/单线程环境说明；
- **解锁声明**：区分服务商宣传的“品牌声明”与本站工程师的“实测确认”。

## 二、评测生成与更新流程

```mermaid
flowchart LR
    Step1["1. 官方参数采集"] --> Step2["2. 本地/机房测速抽样"]
    Step2 --> Step3["3. 证据归档与截图加注"]
    Step3 --> Step4["4. 多维度综合编辑评估"]
    Step4 --> Step5["5. 正式发布与定期复核"]
```

1. **公开数据采集**：由评测人员定期检查服务商官方在售方案，核验是否变更价格或流量规则；
2. **抽样测速**：在特定网络环境下进行节点延迟与吞吐测试，保留完整证据链；
3. **周期性复核**：对页面标注的最后核验日期（`lastVerified`）进行跟踪，防止过期数据误导读者。

## 三、公开纠错机制与流程

我们深知代理服务行业的技术参数、优惠活动与线路拓扑变动极为频繁。任何用户或服务商官方代表如发现本站收录的信息存在任何事实错误，均可提出更正申请：

### 纠错受理范围
1. **套餐资费或流量规格发生官方调整**；
2. **优惠码已过期或折扣力度变动**；
3. **线路类型或支持协议与官方发布存在出入**；
4. **服务商已停止运营或合并**。

### 纠错处理承诺
- 在收到有效反馈并经工程师核实官方页面或测试复核后，我们将在 48 小时内更新页面数据，并在文章的更新历史中如实记录修正事项；
- 纠错仅限事实性数据修正，服务商不可要求删除真实的客观负面评价或实测测速截图。
