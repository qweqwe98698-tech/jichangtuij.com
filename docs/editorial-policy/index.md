# 网站编辑原则

1. **首段直奔主题**：所有文章在 80-120 字内直接解答用户搜索的核心问题。
2. **拒绝虚假承诺**：严禁出现“100%稳定、永不封锁、全网最快”等无法核验的营销违禁词。
3. **纠错机制**：如品牌方调整资费或参数，用户与厂商均可通过反馈渠道提出事实更正。
